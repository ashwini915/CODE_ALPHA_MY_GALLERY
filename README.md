# 🖼️ Image Gallery

A modern and responsive **Image Gallery Website** built using **HTML, CSS, and JavaScript**.
The gallery includes smooth animations, image filters, hover effects, and a lightbox with Next/Previous navigation.

## ✨ Features

* 📸 Responsive image gallery
* 🔍 Lightbox image preview
* ⏮️ Previous and ⏭️ Next image navigation
* 🎨 Smooth hover effects and transitions
* 📱 Fully responsive design
* 🗂️ Category-based image filters
* 🌿 Nature category
* 🐾 Animals category
* ✈️ Travel category
* 💻 Technology category
* 🏠 All images category
* ❌ Lightbox close button
* ⚡ Built with vanilla JavaScript

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, Grid/Flexbox, animations and responsive design
* **JavaScript** – Gallery navigation, filters and lightbox functionality

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Click on an image to open the lightbox.
5. Use the **Next** and **Previous** buttons to navigate.
6. Use the category buttons to filter images.
